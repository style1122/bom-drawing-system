## 修复今日下载不统计（fix c4795e5 后半，关键 bug）
- 现象：用户 UI 下载图纸后，「今日下载」计数仍为 0。后端日志 `target/logs/bom-system.log` 实锤：`WARN 记录下载审计失败 drawingId=220/221`。
- 根因链：下载接口 `/api/drawing/download/` 在 `LoginInterceptor.preHandle` 白名单放行（不放行登录校验）→ `request.setAttribute("userId",...)` 永不执行 → `DrawingController.download` 里 `uid=(Long)request.getAttribute("userId")` 恒为 `null` → `auditLogService.log(null,"下载",...)` 向 `audit_log(user_id BIGINT NOT NULL)` 插 NULL → 触发 NOT NULL 约束异常 → 被 try-catch 吞掉 → 无审计记录 → `countTodayByOperation("下载")` 恒为 0。
- 修复（`DrawingController.download`）：uid 为空时先从 `Authorization` 头 / `token` 参数经 `LoginInterceptor.getUserIdByToken(token)` 解析真实用户；仍为空降级为匿名哨兵 `0L`（满足 user_id 非空）。`findRecent` 用 LEFT JOIN，匿名行仍可显示（user_name 为空）。
- 注意：公开分享下载走 `SharePageController`（未落审计），仍不计入「今日下载」；如需纳入要再补。
- 后端未在本环境编译（Maven 不可用），需在构建机 `mvn clean package -DskipTests` 重新打包部署后方生效。
- 提交 c4795e5 已推送 origin/main（HEAD 核验一致）。
