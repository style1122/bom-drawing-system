## 修复 ZIP 上传中文文件名乱码

**问题**：`ZipInputStream` 默认用 UTF-8 读取文件名，但 Windows 下创建的 ZIP 文件名是 GBK 编码，导致中文存入数据库后变乱码（如"集线盒盖"变成"闆嗙嚎鐩掔洊"）。

**修复**：`DrawingService.java` 第93行 `new ZipInputStream(file.getInputStream())` 改为 `new ZipInputStream(file.getInputStream(), Charset.forName("GBK"))`，新增 `import java.nio.charset.Charset`。

**注意**：已入库的乱码数据无法自动修复，需删除旧记录后重新上传 ZIP 文件。
