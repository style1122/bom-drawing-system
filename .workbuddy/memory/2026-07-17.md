# 2026-07-17 工作日志

## 图纸管理模块分页功能实现

为图纸管理模块（DrawingManage.vue）实现了服务端分页，支持每页 20/50/100 条可选。

### 改动文件

**后端（Java）：**
- `bom-common/.../util/PageResult.java`（新增）— 通用分页结果封装 `{list, total, page, size}`
- `bom-dao/.../mapper/MaterialMapper.java` — 新增 `findAllPaged`、`countAll`、`searchPaged`、`countSearch` 四个方法
- `bom-dao/.../mapper/MaterialMapper.xml` — 将公共 JOIN 和 WHERE 提取为 `<sql>` 片段，新增分页查询（SQL Server `OFFSET/FETCH NEXT`）和 COUNT 查询
- `bom-service/.../MaterialService.java` — 新增 `getAllPaged(page, size)` 和 `searchPaged(keyword, page, size)` 方法
- `bom-web/.../controller/MaterialController.java` — `/list` 和 `/search` 端点接受 `page`、`size` 参数（默认 1、20），返回 `PageResult`

**前端（Vue）：**
- `bom-frontend/src/api/material.js` — `getMaterialList` 和 `searchMaterial` 增加 `page`、`size` 参数
- `bom-frontend/src/views/drawing/DrawingManage.vue` — 添加 `el-pagination` 组件，分页状态管理，跨页序号，搜索/重置回第一页，删除最后一行自动回退一页

### 验证
- 前端 `vite build` 通过
- 后端 `mvn clean compile` 通过（仅有 POI 过时 API 警告，与本次改动无关）
