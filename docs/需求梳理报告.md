# BOM 图纸管理系统 — 需求梳理报告

> 版本：v1.0 | 日期：2026-07-16 | 状态：一期已交付

---

## 1. 项目背景

制造业企业在日常生产中，BOM（Bill of Materials，物料清单）所关联的工程图纸是研发、采购、生产等环节的核心资料。传统方式下图纸分散存放于个人电脑或共享文件夹中，存在以下问题：

- **版本混乱**：图纸修订后旧版本未归档，各部门使用不一致的版本
- **检索困难**：按物料编码查找图纸效率低下
- **权限失控**：采购部门无法安全、可控地获取外发图纸
- **操作无痕**：图纸的查看、下载行为无法追溯

为此，建设一套集中管理、权限可控、操作可追溯的 BOM 图纸管理系统，作为企业数字化转型的基础设施之一。

## 3. 核心功能模块

### 3.1 用户管理

- **注册**：用户自行注册账号，注册后状态为"待审核"
- **审核**：管理员审核新注册用户，审核通过后方可登录
- **登录**：用户名 + 密码认证
- **停用/启用**：管理员可停用离职或违规账号，也可重新启用
- **重置密码**：管理员可为忘记密码的用户重置密码

### 3.2 图纸管理（核心模块）

- **物料 CRUD**：创建、查看、编辑、删除物料信息（物料编码、名称、规格、图号等）
- **图纸上传**：支持 PDF / STEP / DWG 等常见工程图纸格式
- **PDF 预览**：弹窗方式在线预览 PDF，支持放大、缩小、翻页操作
- **图纸下载**：授权用户可下载原始图纸文件
- **3D 预览**：基于 Three.js 实现 STEP 等 3D 模型的 Web 端预览

### 3.3 仪表盘

- **图纸文件统计**：按格式、按时间维度的图纸数量统计
- **活跃用户数**：统计指定时间段内的活跃用户数量
- **操作日志**：记录"谁在什么时间做了什么"，支持按用户、操作类型、时间范围筛选

### 3.4 图纸分享

- **生成分享链接**：为指定物料生成带唯一 token 的分享链接
- **免登录访问**：采购部通过链接即可查看物料信息和 PDF 预览
- **有效期控制**：分享链接有效期 7 天，到期自动失效
- **下载支持**：分享页面支持图纸文件下载

## 5. 数据流

### 5.1 图纸上传流程

```
用户选择文件 → 前端校验(格式/大小) → 后端接收 → 存储到文件系统
→ 写入图纸表记录 → 写入操作日志 → 返回成功
```

### 5.2 图纸下载流程

```
用户点击下载 → 校验权限(是否登录/角色) → 读取文件 → 流式返回 → 写入操作日志
```

### 5.3 PDF 预览流程

```
用户点击预览 → 获取文件路径 → 前端弹窗加载 PDF.js → 渲染预览
```

### 5.4 图纸分享流程

```
研发工程师点击分享 → 后端生成 token + 设置有效期(7天) → 返回分享链接
→ 采购部打开链接 → 后端校验 token 有效性 → 展示物料信息 + PDF 预览 + 下载
```

## 8. 二期规划

### 8.1 正航 T9 ERP 对接

正航 T9 是企业在用的 ERP 系统，BOM 图纸管理系统需要与其打通：

- **物料数据同步**：从 T9 ERP 同步物料编码、名称、规格等基础信息，避免重复录入
- **BOM 结构对接**：获取 T9 中的 BOM 层级关系，在图纸系统中按 BOM 树展示图纸
- **图号关联**：将图纸系统中的图号与 T9 中的物料图号字段建立映射关系
- **单点登录**：对接 T9 的用户体系，实现统一认证（可选方案）
- **变更通知**：当 T9 中物料发生变更时，通知图纸系统更新关联图纸

### 8.2 其他规划

- 图纸版本管理（修订历史、版本回滚）
- 图纸审批流程（提交 → 审核 → 发布）
- 批量导入/导出物料与图纸
- 移动端适配（企业微信集成）
- 水印功能（预览和下载时添加用户水印）
