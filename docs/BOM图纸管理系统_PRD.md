## 2. 背景与目标

### 2.1 背景

制造型企业日常运营中，BOM 物料关联的工程图纸（PDF、STEP、DWG 等格式）是研发设计、采购询价、生产装配等环节的核心依据。当前企业面临图纸分散存放、版本混乱、权限管理缺失、操作无法追溯等问题，亟需建设一套集中化、安全可控的图纸管理平台。

### 2.2 产品目标

1. **集中管理**：统一存储和管理所有 BOM 关联图纸，消除信息孤岛
2. **安全可控**：基于角色的权限体系，确保图纸仅被授权人员访问
3. **高效协作**：支持在线预览（PDF/3D）、安全分享，减少沟通成本
4. **操作可追溯**：完整记录图纸的查看、下载、分享等操作日志
5. **外部协同**：安全分享机制让采购部等外部角色无需系统账号即可获取图纸

## 3. 用户故事

### 3.1 管理员 (ADMIN)

> 作为 **IT 管理员**，我希望能 **审核新注册用户、管理账号状态**，以便 **确保只有合法人员能访问系统**。

> 作为 **IT 管理员**，我希望能 **查看所有用户的操作日志**，以便 **在发生信息安全事件时追溯责任**。

### 3.2 研发工程师 (ENGINEER)

> 作为 **研发工程师**，我希望能 **上传和管理物料图纸**，以便 **将设计成果归档并供团队使用**。

> 作为 **研发工程师**，我希望能 **在线预览 PDF 和 3D 模型**，以便 **无需安装专业软件即可查看图纸内容**。

> 作为 **研发工程师**，我希望能 **生成分享链接发给采购部**，以便 **采购部能及时获取图纸进行询价，而无需为其创建系统账号**。

### 3.3 生产查看者 (VIEWER)

> 作为 **车间工艺员**，我希望能 **按物料编码搜索并查看图纸**，以便 **在生产现场快速确认加工要求**。

### 3.4 采购部（外部用户）

> 作为 **采购人员**，我希望能 **通过分享链接查看物料信息和图纸**，以便 **获取准确的规格参数进行供应商询价**。

## 4. 功能需求（EARS 原则）

### 4.1 用户管理

#### 4.1.1 用户注册

| 类型 | 描述 |
|------|------|
| **Ubiquitous** | 系统应始终对用户注册请求进行服务端校验，用户名不得重复，密码长度不少于 6 位 |
| **Event-driven** | 当用户提交注册表单时，系统应创建用户记录并将其状态设为"待审核"，同时提示用户等待管理员审核 |
| **Unwanted** | 如果用户名已存在，系统应返回明确错误提示"该用户名已被注册" |
| **State-driven** | 当用户状态为"待审核"时，该用户无法登录系统 |

#### 4.1.2 用户登录

| 类型 | 描述 |
|------|------|
| **Ubiquitous** | 系统应始终对登录密码进行加密比对，不在日志中记录明文密码 |
| **Event-driven** | 当用户提交登录表单且验证通过时，系统应创建会话并将用户重定向至仪表盘页面 |
| **Unwanted** | 如果用户名不存在或密码错误，系统应统一返回"用户名或密码错误"而不区分具体原因 |
| **Unwanted** | 如果账号已被停用，系统应返回"该账号已被停用，请联系管理员" |
| **Unwanted** | 如果账号状态为"待审核"，系统应返回"该账号尚未通过审核，请等待管理员审核" |
| **State-driven** | 当用户连续 5 次输入错误密码时，系统应临时锁定该账号 30 分钟 |

#### 4.1.3 管理员审核用户

| 类型 | 描述 |
|------|------|
| **Ubiquitous** | 审核用户功能应始终仅对 ADMIN 角色开放 |
| **Event-driven** | 当管理员点击"审核通过"时，系统应将用户状态从"待审核"变更为"正常"，并记录操作日志 |
| **Event-driven** | 当管理员点击"审核拒绝"时，系统应将用户状态变更为"已拒绝"，并记录操作日志 |
| **Unwanted** | 如果目标用户不存在或已被审核，系统应返回"该用户状态不允许此操作" |

#### 4.1.4 停用/启用账号

| 类型 | 描述 |
|------|------|
| **Ubiquitous** | 停用/启用功能应始终仅对 ADMIN 角色开放，且管理员不能停用自己的账号 |
| **Event-driven** | 当管理员点击"停用"时，系统应将目标用户状态变更为"已停用"，已登录的该用户会话立即失效 |
| **Event-driven** | 当管理员点击"启用"时，系统应将目标用户状态恢复为"正常" |
| **Unwanted** | 如果管理员试图停用自己，系统应返回"不能停用当前登录账号" |

#### 4.1.5 重置密码

| 类型 | 描述 |
|------|------|
| **Ubiquitous** | 重置密码功能应始终仅对 ADMIN 角色开放 |
| **Event-driven** | 当管理员执行重置密码操作时，系统应将目标用户的密码重置为默认密码，并强制该用户在下次登录时修改密码 |
| **Unwanted** | 如果目标用户不存在，系统应返回"用户不存在" |

### 4.2 图纸管理

#### 4.2.1 物料 CRUD

| 类型 | 描述 |
|------|------|
| **Ubiquitous** | 物料编码应在系统内全局唯一 |
| **Event-driven** | 当研发工程师创建物料时，系统应生成物料记录并记录操作日志 |
| **Event-driven** | 当研发工程师编辑物料信息时，系统应更新物料记录并记录操作日志 |
| **Event-driven** | 当研发工程师删除物料时，系统应同时删除关联的所有图纸文件和分享记录，并记录操作日志 |
| **Unwanted** | 如果物料编码已存在，系统应返回"物料编码已存在，请检查后重试" |
| **Unwanted** | 如果物料下已有图纸文件，删除物料前应弹出二次确认"该物料下存在 N 个图纸文件，删除后不可恢复，是否继续？" |
| **Optional** | VIEWER 角色可查看物料列表和详情，但无创建、编辑、删除权限 |

#### 4.2.2 图纸上传

| 类型 | 描述 |
|------|------|
| **Ubiquitous** | 系统应始终校验上传文件格式，仅允许 PDF、STEP、STP、DWG、DXF、IGS、IGES 格式 |
| **Ubiquitous** | 单个上传文件大小不得超过 50MB |
| **Event-driven** | 当用户选择文件并提交上传时，系统应将文件存储至服务器文件系统，在图纸表中创建记录，并写入操作日志 |
| **Unwanted** | 如果文件格式不在允许列表中，系统应拒绝上传并提示"不支持的文件格式，允许的格式：PDF、STEP、DWG 等" |
| **Unwanted** | 如果文件大小超过 50MB，系统应拒绝上传并提示"文件大小超过 50MB 限制" |
| **Unwanted** | 如果上传过程中网络中断，系统应提示"上传失败，请重试"，不留存不完整的文件 |

#### 4.2.3 PDF 预览

| 类型 | 描述 |
|------|------|
| **Ubiquitous** | PDF 预览应始终在浏览器端通过 PDF.js 渲染，不依赖客户端 PDF 软件 |
| **Event-driven** | 当用户点击"预览"按钮时，系统应弹出模态窗口加载 PDF 文件，并提供放大、缩小、翻页控件 |
| **Unwanted** | 如果 PDF 文件加载失败（文件损坏或不存在），系统应提示"图纸文件加载失败，请联系管理员" |
| **Optional** | 预览窗口应支持全屏模式 |

#### 4.2.4 图纸下载

| 类型 | 描述 |
|------|------|
| **Ubiquitous** | 下载操作应始终写入操作日志，记录下载人、下载时间、下载的物料和文件名 |
| **Event-driven** | 当用户点击"下载"按钮时，系统应以流式方式返回原始图纸文件，触发浏览器下载 |
| **Unwanted** | 如果图纸文件在服务器上不存在，系统应返回"文件不存在，可能已被删除" |

#### 4.2.5 3D 预览

| 类型 | 描述 |
|------|------|
| **Ubiquitous** | 3D 预览应始终基于 Three.js 在浏览器端渲染 |
| **Event-driven** | 当用户点击"3D 预览"按钮且文件格式为 STEP/STP 时，系统应在弹窗中加载并渲染 3D 模型 |
| **Unwanted** | 如果文件格式不支持 3D 预览，系统应提示"该文件格式不支持 3D 预览" |
| **Unwanted** | 如果 3D 模型加载超时（超过 30 秒），系统应提示"模型加载超时，请重试或下载后本地查看" |
| **Optional** | 3D 预览应支持旋转、缩放、平移操作 |

### 4.3 仪表盘

#### 4.3.1 图纸文件统计

| 类型 | 描述 |
|------|------|
| **Ubiquitous** | 仪表盘应始终仅对已登录用户可见 |
| **Event-driven** | 当用户进入仪表盘页面时，系统应加载并展示当前图纸总数、各格式数量分布、近期上传趋势 |
| **Optional** | 支持按时间范围（本周、本月、本季度、自定义）筛选统计数据 |

#### 4.3.2 活跃用户数

| 类型 | 描述 |
|------|------|
| **Event-driven** | 当用户进入仪表盘页面时，系统应展示近 7 天、近 30 天的活跃用户数 |
| **Unwanted** | 如果统计周期内无活跃用户，应显示"0"而非空白或报错 |

#### 4.3.3 操作日志

| 类型 | 描述 |
|------|------|
| **Ubiquitous** | 系统应始终自动记录所有关键操作，不可被关闭或绕过 |
| **Ubiquitous** | 操作日志应始终包含：操作人、操作时间、操作类型、操作对象、IP 地址 |
| **Event-driven** | 当管理员在日志页面设置筛选条件并查询时，系统应返回符合条件的日志列表，支持按用户、操作类型、时间范围筛选 |
| **Unwanted** | 如果查询条件下无匹配日志，系统应提示"未找到符合条件的操作日志" |
| **Optional** | 支持导出日志为 Excel 文件 |

### 4.4 图纸分享

#### 4.4.1 生成分享链接

| 类型 | 描述 |
|------|------|
| **Ubiquitous** | 分享链接中的 token 应始终使用加密安全的随机字符串（长度不少于 32 位） |
| **Ubiquitous** | 分享功能应始终仅对 ENGINEER 和 ADMIN 角色开放 |
| **Event-driven** | 当用户点击"生成分享链接"时，系统应创建分享记录（包含唯一 token、关联物料 ID、创建人、有效期 7 天），并返回完整分享 URL |
| **Unwanted** | 如果同一物料已有有效分享链接，系统应提示"该物料已有有效分享链接，有效期至 YYYY-MM-DD，是否重新生成？" |

#### 4.4.2 分享页面访问

| 类型 | 描述 |
|------|------|
| **Ubiquitous** | 分享页面应始终无需登录即可访问 |
| **Event-driven** | 当访问者打开分享链接时，系统应校验 token 有效性并展示物料信息和 PDF 预览 |
| **State-driven** | 当分享链接过期（超过 7 天）时，系统应展示"该分享链接已过期"页面 |
| **Unwanted** | 如果 token 不存在或无效，系统应展示"无效的分享链接"页面 |
| **Optional** | 分享页面应提供图纸文件下载按钮 |

#### 4.4.3 分享有效期管理

| 类型 | 描述 |
|------|------|
| **Ubiquitous** | 分享链接的有效期应始终为自创建之日起 7 天 |
| **Event-driven** | 当分享链接过期时，系统应自动将其状态标记为"已过期"，不可再通过该链接访问 |
| **Optional** | 管理员可在后台手动撤销某个分享链接，使其提前失效 |

## 5. 非功能需求

### 5.1 性能要求

| 指标 | 要求 |
|------|------|
| 页面加载时间 | 首屏加载 ≤ 3 秒（常规网络环境） |
| PDF 预览加载 | ≤ 5 秒（10MB 以内文件） |
| 图纸上传速度 | 50MB 文件上传 ≤ 30 秒（局域网环境） |
| 并发用户数 | 支持 50 用户同时在线操作 |
| 3D 模型加载 | ≤ 10 秒（20MB 以内 STEP 文件） |

### 5.2 安全要求

| 要求 | 说明 |
|------|------|
| 密码加密存储 | 使用 BCrypt 等不可逆算法存储密码哈希 |
| SQL 注入防护 | 使用 MyBatis 参数化查询，禁止拼接 SQL |
| XSS 防护 | 前端输出进行 HTML 转义，禁止直接渲染用户输入内容 |
| CSRF 防护 | 关键操作（删除、审核等）使用 CSRF Token 校验 |
| 文件上传安全 | 校验文件 MIME 类型和扩展名，禁止上传可执行文件 |
| 操作日志 | 完整记录关键操作，日志不可删除 |
| 会话管理 | 会话超时时间 30 分钟，支持主动登出 |
| 分享链接安全 | Token 使用 SHA-256 随机生成，有效期 7 天，过期自动失效 |

### 5.3 兼容性要求

| 项目 | 要求 |
|------|------|
| 浏览器 | Chrome 90+、Edge 90+、Firefox 88+ |
| 分辨率 | 最低支持 1366×768，推荐 1920×1080 |
| 数据库 | SQL Server 2019 |
| JDK | JDK 8 或 11 |

### 5.4 可维护性要求

- 后端代码遵循 MVC 分层架构，Service 层负责业务逻辑
- 数据库变更使用 SQL 迁移脚本管理
- 关键业务异常应记录详细错误日志，便于排查
- 图纸文件按"年份/月份/物料编码"的目录结构存储

## 6. 验收标准

| AC-05 | 重置密码 | 密码重置为默认值，下次登录强制修改 |

### 6.2 图纸管理

| 编号 | 验收项 | 验收条件 |
|------|--------|----------|
| AC-06 | 物料创建 | 物料编码唯一，创建成功后在列表中可见 |
| AC-07 | 图纸上传 | 支持 PDF/STEP/DWG 格式上传，非法格式被拒绝 |
| AC-08 | PDF 预览 | 弹窗展示，支持放大缩小翻页 |
| AC-09 | 图纸下载 | 点击下载后浏览器触发文件下载 |
| AC-10 | 3D 预览 | Three.js 正确渲染 STEP 模型，支持旋转缩放 |
| AC-11 | 权限控制 | VIEWER 仅可查看，无编辑/删除/上传权限 |

### 6.3 仪表盘

| 编号 | 验收项 | 验收条件 |
|------|--------|----------|
| AC-12 | 图纸统计 | 正确展示各格式图纸数量和上传趋势 |
| AC-13 | 活跃用户 | 正确统计活跃用户数 |
| AC-14 | 操作日志 | 完整记录操作人、时间、类型、对象，支持筛选 |

### 6.4 图纸分享

| 编号 | 验收项 | 验收条件 |
|------|--------|----------|
| AC-15 | 生成链接 | 生成唯一分享链接，含 32 位以上 token |
| AC-16 | 免登录访问 | 采购部无账号可通过链接查看物料和 PDF 预览 |
| AC-17 | 有效期 | 7 天后链接自动失效，展示过期提示 |
| AC-18 | 下载 | 分享页面支持图纸文件下载 |
